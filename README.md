# Color Picker

A compact React app for selecting a color and seeing the choice reflected in the interface. Created as a **Fullstack Academy assignment**, this project is a hands-on exercise in React state and interactive UI.

## Preview

![Color Picker app showing the color selection interface](https://github.com/matwal42083/picker/assets/115494989/dd9dab09-4439-4644-af43-7d35bdcf897b)

The app starts with three choices: violet, blue, and red. Select a color to display its name in the header and highlight the matching color swatch.

**Demo:** [Watch the color picker in action](https://github.com/matwal42083/picker/assets/115494989/079d3301-8195-4372-9bff-59e778f90eb3)

## Built with

- React
- JavaScript
- CSS
- Vite

## Run locally

You'll need [Node.js](https://nodejs.org/) and npm.

```sh
git clone https://github.com/matwal42083/picker.git
cd picker
npm install
npm run dev
```

Open the local URL printed by Vite.

## Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build in `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Check the source files with ESLint |
