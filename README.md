# Color Picker

A simple interactive color picker built as an assignment for Fullstack Academy. Select a color to see it highlighted and displayed in the header.

[Watch the color picker demo](https://github.com/matwal42083/picker/assets/115494989/079d3301-8195-4372-9bff-59e778f90eb3)

## Features

- Choose from violet, blue, and red.
- See the selected color in the header.
- View the selected color highlighted in the picker.

## Built with

- React
- JavaScript
- CSS
- Vite

## Run locally

You’ll need [Node.js](https://nodejs.org/) and npm installed.

```sh
npm install
npm run dev
```

Open the local URL printed by Vite in your browser.

## Available scripts

- `npm run dev` — start the development server.
- `npm run build` — create a production build in `dist/`.
- `npm run preview` — preview the production build locally.
- `npm run lint` — run ESLint on the source files.
